# Taiwan Physical Photobook Leads

## Which fresh physical titles had a live MuseBooks match?

### Takeaway

The newly surfaced physical books from Taiwan cheerleaders and creators in this pass are already represented in the live catalog; none warrants a second work import or R2 upload. One catalog-quality issue surfaced: 瑟七’s work-level cover shown by MuseBooks is the digital-specific artwork, while the direct physical listing shows a different print-cover design.

### Inferences

- The current catalog already covers the specific recently surfaced physical works above; duplicate API results are sufficient to stop duplicate DB/R2 writes. The clearest actionable follow-up is a cover/edition-data review for 瑟七 and a release-date correction review for 彭彭 and 夏蕾.

### Gaps

- The Kingstone image of 瑟七’s print cover carries a SAMPLE watermark, so it documents the physical cover design but is not a clean reusable cover asset. A flat, final physical-cover file was not found in this pass. [Kingstone product image](https://assets.kingstone.com.tw/prodassets/39185_008f48acb8afd873eac3451b1efe2fb.jpg)
- No cover uploads, catalog writes, or DB changes were made in this research pass; all live API calls were read-only. The API images were visually inspected only to compare 瑟七’s current shared work cover with the listed physical edition.
